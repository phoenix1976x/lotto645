- 🔮 **오늘·내일 운세** — 양력/음력 생년월일(태어난 시간은 모름도 가능)만 넣으면 오늘·내일 일진 간지와 내 사주(일간·오행·용신·지지 합충)를 대조해 오늘 카드·내일 카드를 바로 보여 줍니다. 카드마다 좋은 흐름·조심할 점, 💰 금전운, 📈 주식·단타 컨디션, 🍀 로또·행운 숫자 운(재미용)이 들어갑니다. 금전·주식·로또 내용은 투자 권유나 매매 판단 근거가 아니고, 로또 당첨 확률은 모든 번호가 같습니다.
- 📜 **토정비결 144괘 · 🧭 사주** — 메인 카드 아래에서 접혀 있다가 누르면 펼쳐집니다. 토정비결은 조회 연도(2026 병오년·2027 정미년)를 고를 수 있고 총운·12개월·작괘 근거를, 사주는 네 기둥·오행 분포·용신·해석을 보여 줍니다.
- 🎱 **로또 6/45** — 자동·반자동(고정 번호 1~5개), 당첨금 나눠먹기 줄이기, 판매 마감 카운트다운
- 🎟️ **연금복권 720+** — 세트(1~5조)·낱장 1/5장, 조·자리별 반자동, 단순 배열 피하기

입력값은 전부 브라우저 안에서만 계산하며 서버로 보내거나 저장하지 않습니다.

해시로 바로 열 수 있습니다 — `#tojeong`·`#saju`·`#daily`(오늘·내일 운세), `#lotto`, `#720`.
